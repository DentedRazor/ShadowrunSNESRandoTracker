# ShadowrunSNESRandoTracker
An interface for tracking acquired Key Words and Key Items in seeds of the [Shadowrun (SNES) Randomizer](https://github.com/Osteoclave/shadowrun-randomizer) by Osteoclave. 

This requires the font file "Steelflight.ttf", which can be found [here](https://fontstruct.com/fontstructions/show/864606/steelflight).

AI was not used for making this, just googling for CSS and HTML answers as needed.

**Setup**
1. Download the file "Shadowrun.html" and put it in desired location on your computer.
2. Download the font file "Steelflight.ttf" in that folder and put it in the same location as "Shadowrun.html".

**General Use**

Here are instructions to use this in either a web browser or an OBS browser.

**Web Browser**
1. In a web browser, put the path "file:///C:/Shadowrun/Shadowrun.html" in the "Address" field, updating it to match the location of the file and press "enter".
2. The interface should show up.
3. You can click the buttons to toggle their color.

**OBS Browser**
1. In your scene, create a "Browser".
2. Set URL as the path "file:///C:/Shadowrun/Shadowrun.html", updating it to match the location of the file.
3. Set Width to 450.
4. Set Height to 258.
5. Clear the "Custom CSS" field.
6. To interact with it, right-click the browser item you created and select "Interact" to open a little window to put in a convenient place.

**Other Notes**

I have the colors set to match the in-game menu and text, but the variables in the :root class of the file can be edited to customize those.
