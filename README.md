# ShadowrunSNESRandoTracker
An interface for tracking acquired Key Words and Key Items in seeds of the Randomizer of Shadowrun (SNES) by Osteoclave.

This requires the font file "Steelflight.ttf", which can be found by searching "Steelflight font" on a web search engine.

1. Download the file "Shadowrun.html" and put it in desired location on your computer.
2. Download the font file "Steelflight.ttf" in that folder and put it in the same location as "Shadowrun.html".
3. In a web browser, put the path "file:///C:/Shadowrun/Shadowrun.html" in the "Address" field, updating it to match the location of the file and press "enter".
4. The interface should show up. You can click the buttons to toggle their color.

I have the colors set to match the in-game menu and text, but the variables in the :root class of the file can be edited to customize those.

Enjoy and have fun!
